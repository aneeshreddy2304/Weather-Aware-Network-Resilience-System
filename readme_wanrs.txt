WANRS — documentation entry point

The maintained documentation is README.md in this directory.
The existing dependency file is requirements_txt.txt.

See README.md for implemented architecture, artifact prerequisites, synthetic-target
interpretation, setup, and evaluation limitations. The older narrative used obsolete
filenames/city examples and synthetic error figures without reproducible provenance;
those figures are not current validated benchmarks.

The project uses Open-Meteo weather inputs and rule-generated network targets.
No real network telemetry or automatic mitigation control is implemented.
